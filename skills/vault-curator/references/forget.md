# Forget Stored Material

Read this only when the learner explicitly asks to remove stored learning material.

1. Identify the exact authoritative bindings and linked files affected.
2. Explain what will stop being current and what Git history may still retain.
3. Resolve references from Coach State, Learning Strategy, other Topics, projections, and public exports when applicable.
4. Decide explicitly whether advisory objects are removed, superseded, or retained as historical context.
5. Obtain confirmation for the destructive plan unless already explicitly authorized.
6. Remove authoritative bindings before deleting now-unreferenced files.
7. Verify that remaining authority contains no broken references.

Do not reinterpret forgetting as evidence that learning never occurred. This is a storage/lifecycle operation, not a mastery reassessment.
