# Public Export

Read this only when preparing material for public sharing.

Use an explicit whitelist of selected Topics/notes/fields. Exclude by default:

- private reflections;
- raw session material;
- credentials or unnecessary identifiers;
- unsupported or unresolved claims presented as facts;
- Coach State and portfolio advisory hypotheses unless explicitly selected;
- detailed evidence logs that are not necessary for the public artifact.

Derived public material must not become learner-state authority. Never change the private repository's visibility automatically.

Before writing an export, preview the selected material and privacy exclusions. Use the structural write contract only when persistent export metadata or files will be created.
