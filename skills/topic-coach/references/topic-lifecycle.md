# Topic Lifecycle

Read this reference only when Topic Coach is creating/resuming a Topic, deciding its boundary, adapting its roadmap, or choosing/persisting the next Topic-local action.

## Goal And Topic Boundary

A learner naming an area does not automatically make that area a new Topic. Decide whether it is better represented as:

- a Concept inside an existing Topic;
- a roadmap milestone or Concept cluster inside an existing Topic;
- an extension/refinement of an existing Topic;
- a genuinely new Topic with its own bounded, observable target capability.

Prefer the smallest durable Topic boundary that can support one coherent goal, one adaptive roadmap, one current focus, and one next action without becoming a miscellaneous knowledge bucket.

Turn a clear learning intent into:

- an observable `targetCapability`;
- useful success criteria;
- an initial/current capability assessment when useful.

When the outcome is unclear, clarify only enough to distinguish understanding, source-code reading, implementation, research comparison, or another learner-defined capability.

After boundary assessment:

1. determine whether the area belongs in an existing Topic or a new one;
2. define/refine target capability;
3. retrieve relevant Topic evidence;
4. assess current capability when useful;
5. verify uncertain gaps rather than inventing them;
6. create/adapt the Topic roadmap when useful;
7. choose the next useful within-Topic action.

Do not choose among unrelated Topics here. Ask Coach owns portfolio prioritization and system-initiated new-Topic recommendation.

## Start A New Topic

Create a Topic only after the learner explicitly chooses to pursue it.

- use a stable lowercase-hyphenated ID;
- preserve the learner's goal and observable target capability;
- create a lightweight capability roadmap when useful;
- initialize state without inventing prior mastery;
- reread saved authority before claiming continuity.

If the Topic came from an Ask Coach candidate, advisory context may inform the initial goal/target capability, but the learner's explicit choice controls creation.

## Resume An Existing Topic

Restore the minimum state needed to continue accurately:

- goal and target capability;
- roadmap and active milestone;
- current focus;
- known gaps and important unassessed areas;
- evidence/mastery relevant to the current target;
- Topic-local review needs;
- relevant linked notes/sessions only when needed;
- persisted next action and reason.

Read Learning Strategy when it can materially improve the lesson, but do not synthesize or mutate cross-Topic strategy here.

When taking over after learning has already begun, distinguish previous exposure, demonstrated understanding/application, relevant but unassessed areas, and evidence-supported known gaps. Do not manufacture evidence for earlier work that has not been demonstrated.

## Roadmap Planning And Adaptation

The roadmap is a medium-term **capability path**, not chapter coverage.

Use milestone statuses:

- `planned`
- `active`
- `demonstrated`
- `blocked`

Normally keep one primary active milestone. Do not infer milestone completion from average Concept mastery or content coverage; judge the milestone's target capability from appropriate evidence.

Adapt the roadmap when Topic-local evidence changes the useful route, including:

- a milestone becoming demonstrated;
- a blocking gap appearing or resolving;
- the learner changing this Topic's target capability;
- an older roadmap no longer fitting current Topic state.

Keep roadmap, `currentFocus`, and `nextStep` distinct.

## Choose The Next Useful Action

`nextStep` is Topic-local learner state. Choose it from candidates inside the current Topic:

- the active milestone;
- Concept prerequisites;
- local review need;
- practice form;
- application task.

Persist when useful:

- `nextStep`
- `nextStepReason`
- `nextStepTargets`

Do not encode portfolio choices such as switching to another Topic, opening a new Topic, or reviewing another Topic inside `nextStep`. Ask Coach owns those decisions.

An unanswered but still-useful task may remain the next step. Non-response alone is not evidence or failure.
