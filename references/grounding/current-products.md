# Current Products And Services Source Selection

Read this when grounding current product/service capabilities, limits, availability, pricing-adjacent factual behavior, ecosystem recommendations, or other fast-moving operational claims.

Prefer current first-party documentation for factual capabilities, limits, supported platforms, and official behavior. Use dated recent sources when first-party material is incomplete or when independent confirmation matters.

Treat words such as `current`, `latest`, `now`, `recommended`, `available`, and `still supported` as freshness triggers.

Do not reuse an old verification merely because the product name is unchanged. Refresh when product version, plan, region, feature availability, or relevant documentation may have changed.
