# Save meaningful Learning Updates by default

Invoking Learning Coach authorizes it to save each meaningful Learning Update
to the Learning Vault automatically, unless the learner opts out for that
interaction. An update stores distilled state, evidence, review activity, and
strategy insights rather than raw chat transcripts; conversation with no
durable learning change creates no update. Deletion, conflict resolution, and
Public Export remain separately consequential actions rather than implicit
parts of automatic saving.
