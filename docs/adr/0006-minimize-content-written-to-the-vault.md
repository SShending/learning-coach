# Minimize content written to the Learning Vault

Learning Updates must never store credentials, tokens, private keys, verification
codes, payment secrets, or comparable secrets. Sensitive personal or workplace
context is abstracted to the minimum learning-relevant fact by default, while
knowledge gaps, misconceptions, observed performance, and Learning Strategy
remain eligible for automatic saving because they are the Vault's core private
record. Raw chat, uploaded files, proprietary code, and substantial copied
source material require case-specific learner confirmation before any excerpt
is stored.
