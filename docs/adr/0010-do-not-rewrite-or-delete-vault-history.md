# Do not rewrite or delete Learning Vault history

Learning Coach may Forget material by removing it from current Learning State,
Mastery Evidence, review plans, and future use, while explicitly warning that
prior Git history still contains it. V3 will not rewrite or force-update Git
history and will not request repository deletion permission; a
learner who requires historical erasure must create a clean Vault containing
only material they choose to retain, then remove the old repository directly
in GitHub.
