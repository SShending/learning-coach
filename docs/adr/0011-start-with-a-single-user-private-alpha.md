# Start with a single-user private alpha

Learning Coach v3 will first ship as a private alpha for one learner, using the
agent-memory Topic to validate the learning loop, Learning Vault model, and MCP
tool contracts under real use. The architecture must not preclude later
multi-user operation, but v3 will not implement public plugin distribution,
multi-tenant administration, broad onboarding, or production support before the
core learning behavior is shown to be useful.
