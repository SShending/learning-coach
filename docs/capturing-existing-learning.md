# Capturing Existing Learning

Learning Coach does not require a learning journey to start from the first step.

If you have already been studying a topic before activating Learning Coach, use the capture workflow to reconstruct your current learning state.

## When to use

Examples:

- You have read papers or documentation before creating a Learning Vault.
- You have implemented part of a project and want to record the progress.
- You want to migrate an existing learning process into Learning Coach.

## Workflow

Ask Learning Coach:

```text
I have already started learning <topic>.

Help me capture my current progress into the Learning Vault.
```

The coach should collect:

- learning goal
- studied materials
- concepts encountered
- things the learner can explain
- implementations or experiments completed
- current difficulties and gaps

Then it should create a learning state that distinguishes:

- studied content
- demonstrated understanding
- unassessed areas
- known gaps

## Important principle

Previous exposure is not the same as mastery.

Learning Coach should record evidence of understanding rather than simply mark a topic as completed.
